PROJETO NÓS · v2.0.0 · 18/10/2026

Um novo espaço para cultivar vínculos.

Migração integral para a referência Layout atual. As 73 fichas do Atlas foram capturadas; o aplicativo apresenta as rotas reais e os seis esboços protegidos descritos no registro.

Atlas e referência têm dados ilustrativos. No aplicativo, Árvore, memórias, conexões, perfis, manifesto e cuidado são esboços sem persistência. Capturas autenticadas usam contas temporárias do banco local. As imagens “Antes” são arquivos históricos; suas alturas e dados podem diferir, portanto não constituem uma medição pixel a pixel.

Aplicativo: 1440×1000 e 390×844; recortes adicionais em 640/768/1024 px. Sem transbordamento nos estados verificados. Clique em uma imagem para abrir a captura completa.
