# Registro — v0.6.0 — 2026-09-29 — Imp. de pesquisa de ferramentas para a stack com Fun. de qualidade e operação

**Status:** pesquisa concluída; nenhuma ferramenta foi instalada ou configurada. **Versão do aplicativo:** 0.6.0, sem incremento por pesquisa documental.

## Objetivo e contexto

Pesquisar projetos externos que possam apoiar o Projeto Nós e sua stack atual: Next.js 16.3.6, React 19.3, TypeScript 7, Tailwind 4, Supabase e Playwright. A pesquisa considerou a Tela 04 — Acordos em andamento, a centralidade de RLS e dados relacionais sensíveis, os comandos locais já disponíveis e a análise de frameworks de IA feita na mesma data. Mudanças locais preexistentes foram preservadas.

## Requisitos e decisões

- **Prioridade para próxima etapa de banco — Supabase CLI + pgTAP:** adicionar testes SQL transacionais para grants, RLS, RPC e acessos negativos por identidade, começando por Acordos quando a migração puder ser testada em local Supabase. Supabase CLI já existe no projeto; pgTAP é integrado a `supabase test db`. Isso cobre contratos de banco complementares aos testes Playwright e ao fluxo de duas contas. Exige runtime Docker compatível, hoje indisponível nesta máquina. [CLI](https://github.com/supabase/cli), [guia de testes](https://supabase.com/docs/guides/database/testing) e [testes/RLS](https://supabase.com/docs/guides/local-development/testing/overview).
- **Prioridade após estabilizar integração contínua — Renovate ou Dependabot, somente um:** abrir atualizações revisáveis para o `package-lock.json` e GitHub Actions, com produção e desenvolvimento separados e principais/atualizações de framework mantidas para aprovação manual. Evita deriva de dependências com pouco esforço, desde que a rotina de revisar PRs exista. Renovate oferece granularidade; Dependabot requer menos manutenção e é nativo do GitHub. [Renovate](https://github.com/renovatebot/renovate), [Dependabot](https://docs.github.com/en/code-security/how-tos/secure-your-supply-chain/secure-your-dependencies/configure-version-updates).
- **Prioridade antes de usuários de produção — Sentry Next.js:** captura exceções App Router, server e client e oferece traces. Útil quando há implantação e capacidade de responder aos alertas. A telemetria deve ser minimizada: nunca enviar textos afetivos, payloads de acordos ou tokens; confirmar scrub de dados, retenção, consentimento/configuração e custo antes de habilitar. Nenhuma plataforma de produção está implantada agora. [SDK Next.js](https://github.com/getsentry/sentry-javascript/tree/develop/packages/nextjs).
- **Baixo custo, quando as telas e fluxos estiverem mais estáveis — axe-core com Playwright:** adicionar uma verificação automatizada limitada a jornadas/telas críticas. Encontra violações detectáveis de WCAG, mas não substitui revisão com teclado/leitor de tela; a documentação do axe estima que automação identifica cerca de 57% dos problemas. Preferir integração no Playwright já instalado a duplicar navegador/ferramenta via Pa11y CI. [axe-core](https://github.com/dequelabs/axe-core).
- **Condicionais:** Lighthouse CI após CI e deploy de preview estáveis, com limiares iniciais informativos e sem publicar URLs que contenham dados de Núcleos; Gitleaks se for desejado um scanner local/CI independente; CodeQL quando code scanning estiver disponível no plano/configuração GitHub. O GitHub informa que secret scanning por repositório e push protection dependem do recurso pago Secret Protection em certos tipos de repositório; não assumir disponibilidade gratuita universal. [Lighthouse CI](https://github.com/GoogleChrome/lighthouse-ci), [Gitleaks](https://github.com/gitleaks/gitleaks), [CodeQL Action](https://github.com/github/codeql-action), [GitHub push protection e disponibilidade](https://docs.github.com/en/code-security/concepts/secret-security/push-protection).
- **Não recomendar neste momento:** Turborepo para um app e uma unidade npm; Kysely como segundo acesso ao banco além do `supabase-js`; novo framework de componentes (React Aria/Radix) antes de existir necessidade demonstrada nos controles atuais; Storybook/Chromatic antes de uma biblioteca de componentes com manutenção própria. O Next já fornece bundler/configuração; Playwright cobre E2E atual. [Next.js](https://nextjs.org/docs/app/guides/testing), [Radix](https://github.com/radix-ui/primitives), [React Aria](https://github.com/adobe/react-spectrum).
- Não foi encontrada justificativa para instalar outro agente/MCP de pesquisa de código: Context7 e Octocode já cobrem documentação e pesquisa assistida, conforme estado registrado. A análise AI SDK/Genkit/Mastra também já está documentada em registro separado.

## Evidência e resultado

Foram feitas buscas web e consultadas fontes oficiais dos projetos/documentações em 2026-09-29. As recomendações são adequação estática à stack e aos gargalos registrados; não são prova de compatibilidade ponta a ponta, custo contratado, disponibilidade de plano ou medição. Context7 foi verificado como disponível no estado persistido do projeto, mas não havia ferramenta Context7 MCP callable nesta sessão. Octocode MCP também não estava exposto; a pesquisa de internet foi feita pela ferramenta web, sem afirmar consulta a esses MCPs.
